## Bhaptics Plugin

### Installation

#### As a Game Plugin
- Move this plugin to your project's `Plugins/` folder.

#### As an Engine Plugin
- [Install via the fab](https://www.fab.com/listings/361f1685-ee8d-4618-bf2d-297a44139bdd)


### Supported Versions
- Tested and compatible with Unreal Engine versions 4.26 to 5.6.
